Telegram для Claude

Даёт Claude доступ к вашему Telegram на этом компьютере. Сессия и переписка никуда не отправляются — всё хранится здесь. Версия __VERSION__.

1Аккаунт Telegram

В этой сборке нет API ID. Заполните его в «Дополнительно» внизу страницы.
  1. Откройте Telegram на телефоне.
  2. Настройки → Устройства → Подключить устройство.
  3. Наведите камеру на код.
Код обновляется сам.

У аккаунта включён облачный пароль. Введите его — он уйдёт напрямую в Telegram.

2Подключить к Claude

Пропишет программу в Claude Desktop и, если он установлен, в Claude Code.

Важно знать

  • Claude получает доступ к вашему аккаунту так же, как ещё одно устройство. Отключить — «Выйти» выше или в Telegram: Настройки → Устройства.
  • Чужие сообщения могут содержать «команды» для Claude. Он обучен их не выполнять, но для надёжности держите «Только читать».
  • Telegram может заблокировать аккаунт за рассылки через такие программы. Не просите Claude писать незнакомым людям.
